# Weather App

A responsive weather application built with HTML, CSS, and JavaScript that provides real-time weather information for cities around the world. Users can search for a location and instantly view current weather conditions through a clean and intuitive interface.

## 🌦️ Overview

Weather App allows users to retrieve and display live weather data by entering a city name. The application dynamically updates weather information and presents key meteorological details in an easy-to-read format.

## ✨ Features

* Search weather by city name
* Real-time weather data retrieval
* Dynamic weather information rendering
* Current temperature display
* Weather condition indicators
* User-friendly interface
* Responsive design for desktop and mobile devices
* Error handling for invalid city searches

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript (ES6)

### APIs

* Weather Data API
* Fetch API

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/walidabdulkadir/weather_app.git
```

### Navigate to the Project Directory

```bash
cd weather_app
```

### Run the Application

Open `index.html` in your preferred web browser.

Alternatively, use VS Code Live Server:

```bash
Right Click → Open with Live Server
```

## 🔍 Usage

1. Open the application.
2. Enter a city name in the search field.
3. Click the search button.
4. View the current weather information for the selected location.
